IP Browser is a web browser (WKWebView) that loads its pages from a server the user owns, so websites see that server's IP address. It does not use a Network Extension and does not change the device's network for other apps.

To test:
1. Scan the attached QR code with the iPhone Camera (it opens IP Browser with the key), or in the app tap «I have a key or QR» and paste the key below, then Add.
2. When the address is verified, the start page shows «Sites see only <address>». Open any site.
3. Settings → Leak test shows the address and time zone websites see.

«Install on my server» needs a fresh VPS with a root password: it connects over SSH, installs open-source server software (listed in the app under «What will be installed?») and keeps no password.

No accounts, analytics or backend of our own. Connections to the user's server use standard TLS 1.3 / QUIC. On IPv6-only (NAT64) networks the app reaches the server through the address iOS synthesizes.
