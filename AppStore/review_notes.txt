IP Browser is a web browser (WKWebView) that sends only its own web traffic through a server the user owns. It is not a device VPN: no NEVPNManager, no Network Extension; other apps keep their own network.

To test:
1. Scan the attached QR code with the iPhone Camera (it opens IP Browser with the key), or in the app tap «I have a key or QR» and paste the key below, then Add.
2. When the exit is verified, the start page shows «Sites see only <address>». Open any site.
3. Settings → Leak test shows the address websites see and that WebRTC/WebTransport are not reachable.

«Install on my server» needs a fresh VPS with a root password: it connects over SSH, installs open-source software (Hysteria, Xray-core, Caddy) and keeps no password.

No accounts, analytics or backend of our own. Encryption: standard algorithms only (TLS 1.3, QUIC, X25519/ML-KEM-768). On IPv6-only (NAT64) networks the app dials the server through the address iOS synthesizes.
